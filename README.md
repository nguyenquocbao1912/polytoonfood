# PolyToonFood

PolyToonFood là một ứng dụng giao đồ ăn (Food Delivery App) hiện đại, trực quan và độc đáo với giao diện được thiết kế theo phong cách giao diện Neobrutalism (các khối nổi rõ, viền đen sắc nét, màu sắc rực rỡ).

Dự án này là minh chứng cho việc tích hợp các công nghệ Web mới nhất vào trong một sản phẩm hoàn chỉnh với tốc độ tải trang cực nhanh, trải nghiệm đa mượt mà.

## Công nghệ sử dụng:
1. **Next.js 15 (App Router)** - Đảm nhiệm vai trò khung sườn (Framework) chính, hỗ trợ các tính năng tối ưu SSR/ISR, tối ưu file và hệ thống định tuyến (Routing).
2. **React (Context, Hooks)** - Xử lý logic phía người dùng, quản lý giỏ hàng (Cart) và quản lý dữ liệu toàn cục.
3. **Tailwind CSS** - Công cụ viết CSS siêu tốc giúp tạo ra phong cách Neobrutalism.
4. **Firebase (Google)** - Phụ trách hệ thống Đăng nhập / Đăng ký, đồng thời làm cơ sở dữ liệu thời gian thực cho ứng dụng (Lịch sử đặt hàng, Lưu món ăn yêu thích).
5. **TheMealDB (API)** - Nguồn cung cấp tài nguyên món ăn vô tận miễn phí dể minh họa cho dự án.

## Mục tiêu dự án:
Dự án được tạo ra với mục đích học tập, thực hành và trình diễn cách quản lý trạng thái, tương tác API và kết nối CSDL hiện đại sử dụng công cụ Trí Tuệ Nhân Tạo (AI) như một người hỗ trợ đắc lực.
